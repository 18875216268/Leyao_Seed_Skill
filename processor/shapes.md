# 形状模板（按需读 · 引导级，非判据）

> **性质**：以下都是**引导**——照抄可以让表达更清楚，**但不是判据**；不用它们不影响验收。
> **何时读**：需要向用户提问、需要标注口径、需要写交付件时。
> **为什么单独放这里**：常驻的准则只放判据（保持精简），形状随用随取（渐进披露）。

## 1. 询问清单（② 规划 · L3 集中询问）

硬要求（在 `flow/2-plan.md` 动作 3）：每项 **2-3 个选项 + 差异与后果 + 默认建议**；一次任务最多一轮。

```text
【问】<L3 问题原文，一句话>
  A. <解读> —— 差异：改变哪部分结果；后果：影响哪个交付物
  B. <解读> —— 差异：…；后果：…
  → 建议 A（一句话理由）；你也可选 B 或给第三解
```

## 2. 口径标注（④ 验收 · ⑤ 交付）

硬要求（在 `flow/4-accept.md` 与 `flow/5-deliver.md`）：**不带口径的数字不出口**。

```text
| 指标   | 数值      | 口径（时间范围 · 主体 · 含税/去重 · 排除项）              |
| --- | --- | --- |
| 销售额 | 1,234 万 | 2026-08-01~08-31 · 药事业部 · 含税 · 剔除退款            |
```

## 3. 报告骨架（⑤ 交付）

硬要求（在 `flow/5-deliver.md` 动作 1）：**结论先行 + 五要素齐备 + 口径随行**。

```text

关键发现
  1. <最重要，带口径>
  2. …
支撑细节
  <表格优先>
口径与假设
  <时间范围 / 主体 / 排除项 / 已知假设>

  <只给有依据 + 可执行的>
```
