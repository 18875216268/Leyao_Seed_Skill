# 资产管理台（轻量 / 零依赖）

可视化管理 `library/routes.json`（总路由）与卡片资产。**人维护、AI 只读**：管理台与 CLI 共用
`library/engine.py` 引擎，`routes.json` 始终是唯一事实源，`ROUTES.md` 始终由引擎渲染。

## 位置与边界

本管理台驻留在**资产管理层内部**（`library/admin/`），与引擎 `library/engine.py` **同层**——
管理的正是所在层，无跨层依赖；`library/assets/` 仍是唯一资产根，与本目录互不干扰。

职责只有两块：**HTTP 适配 + 资产搬运**。业务规则（节点增删的校验与落位、唯一写路径
`commit`、加锁与原子落盘、契约与孤儿校验）全部在引擎内，本目录不复制引擎逻辑、不自行落盘。

**管理台语义「位置即归属」**：位置由人选择，归属（路由树位置）由引擎 `nearest_card` 按
「最近一层卡片」自动推导——目录与卡片 id 一一对应，像文件夹一样互相移动；改位置 = 搬移。

## 启动

唯一入口是 `console.py`（`server.py` 是被导入的模块，不单独启动）：

```text
python library/admin/console.py                # 起后端并自动打开浏览器
python library/admin/console.py --no-browser   # 只起后端（脚本 / 无界面环境）
```

零 pip 依赖（仅 Python 标准库 + 浏览器）。重复启动会被拒绝（端口占用检测），避免旧进程残留。

## 界面

- 顶部：标题「资产の管理」、搜索框（按名称/ID/描述/路径实时过滤）、类型筛选下拉。
- 结果行：`当前共 N 项 — 主页(assets)/…`（面包屑可点击跳转）；异常时显示 `⚠ N 个孤儿资产` / `⚠ N 项契约问题`（点击看详情）。
- 卡片：`#id + 删除/编辑` → 标题 → 类型胶囊 → 位置路径 → 描述（单击弹面板，30 字/行）。
- 右下角：📝 重绘 ROUTES.md、⟳ 刷新、＋ 新增。
- 单击选中（淡蓝高亮），`Ctrl` 多选、`Shift` 连选；单击 `#id` 复制；双击文件夹进入。

## 新增卡片（＋）

弹出「新增」弹窗，五个字段：

| 字段 | 说明 | 留空默认 |
|---|---|---|
| 1. 获取 | 复制源：本机任意文件夹（原生文件夹对话框），必填；**只复制，系统不动源** | —— |
| 2. 位置（归属） | 位置即归属：点候选 = 按卡片定位；或选任意文件夹（含卡片目录下的子目录，限资产根内）；可手输 | 当前所在文件夹 |
| 3. 类型 | 自由文本，可下拉选已有类型 | `公共` |
| 4. 名称 | —— | 复制源文件夹名 |
| 5. 描述 | —— | `暂无描述！请自行分析补全。` |

确认后：复制源被**复制**到 `位置/<6位卡片id>/`；卡片自动归入「位置」的**最近一层卡片**下，并在
`routes.json` 登记节点、重绘 `ROUTES.md`。位置下方实时显示推导出的归属（`归属：…`）。

## 编辑卡片

- **获取（复制源）**：显示本机完整路径；**只复制，系统不会移动 / 新增 / 删除源**。打开弹窗时源不存在 →
  自动指向**当前卡片自己的资产目录**（本机完整路径）。
- **位置（归属）**：位置落在哪个文件夹，卡片就归到**最近一层卡片**下（无卡片则主页顶层）——点候选 = 按卡片
  定位；点「选择」可落在任意文件夹（含卡片目录下的子目录；子目录无编号，不为它建子卡片）；下方实时显示归属。

保存行为：

| 改动 | 行为 |
|---|---|
| 改**获取** | 重置本卡片槽位：清掉自己的旧内容（**保留其子卡片目录**）→ 新复制源复制到当前位置 |
| 改**位置（归属）** | **移动**卡片与资产目录到新位置（含子卡片目录随走、其挂载前缀同步改写）；原位置无资产则从复制源复制；旧目录空壳自动回收 |
| 都改 | 先搬移、再重置槽位（同前两条合并） |
| 都没改 | 不动 |

## 删除卡片

确认弹窗可勾选「同时删除其资产文件夹」：勾选后连同 `library/assets/<...>/` 一并删除，避免留下孤儿资产。

## 孤儿资产

资产根下**未被任何卡片挂载引用**的目录（多为移动 / 删除后的遗留）——顶部提示条出现 `⚠ N 个孤儿资产` 时点击进入处理面板：

- **挂载为卡片**：把该目录直接挂成一张新卡片（标题取目录名，类型默认 `公共`）。
- **删除目录**：删除该目录（仅限资产根内、且未被任何挂载引用——服务端双重复核；**需再点一次确认**）。

删除卡片时未勾「同时删除资产文件夹」→ 其资产目录会变成孤儿，页面会追加一条提醒（点顶部孤儿提示即可处理）。

## 挂载与资产根

**唯一资产根** `library/assets/`，落位规则统一：`library/assets/<位置>/<卡片id>/`（目录名 = 卡片 id）。
资产是**可选内容**：框架不依赖任何具体资产（全部缺失也能跑），"位置"里的子目录只是组织方式。

- 「位置」输入框接受：卡片候选（真实目录）、`主页(assets)/子目录`、本机绝对路径、资产根下的相对路径。
- 原生文件夹对话框覆盖整个资产根（含其下任意子目录）。
- 「删除卡片」的「同时删除资产文件夹」只删**资产根内的目录**（资产根外的路径一律不动）。

## 资产根与安全

- 资产根 = `library/assets/`（界面显示为 `主页(assets)`）；`library/` 自身的引擎/方法论文件与之彻底分离。
- 目录名 = 卡片 id（6 位随机、全局唯一）→ 天然隔离，改关联/改位置不会误删其它卡片的资产；AI 可由 id 直接推导路径。
- 挂载路径强制落在 `leyao-seed-core/` 内（防路径穿越）；落位与对话框均限制在资产根 `library/assets/` 内。
- 所有写操作经引擎**跨进程写锁 + 原子落盘**，与管理台/CLI 并发安全共存。

## 接口

```text
GET    /api/tree                       路由树 + 类型登记表 + 契约问题 + 孤儿资产 + 挂载前缀
GET    /api/exists?path=<本机路径>       复制源存在性探测（打开编辑弹窗时用）
GET    /api/belong?mount=<挂载路径>      按位置求归属（最近一层卡片 id；空 = 主页顶层）
POST   /api/node                       op=add|update（归属由位置推导；含获取复制 / 位置搬移 / 子树联动）
POST   /api/render                     重绘 ROUTES.md
GET    /api/pick-folder                就绪探针
POST   /api/pick-folder                调起原生文件夹对话框（mode=source|dest）
DELETE /api/node?id=<id>[&purge=1]     删除节点（purge=1 同时删资产目录）
DELETE /api/orphan?path=<挂载路径>      删除孤儿资产目录（限资产根内 · 未被挂载引用）
```
